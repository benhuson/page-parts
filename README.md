Page Parts
===============

Manage subsections of a page. Create 'page parts' as children of a page to display in different areas of your templates. Requires WordPress 5.5+ and PHP 7.4+.

Version 1.6 adds page and page part duplication, including nested page parts, and updates compatibility to WordPress 5.5+ and PHP 7.4+.

For more information, view the documentation link on the admin plugins page after activating the plugin.

Installation
------------

1. Upload `plugin-name.php` to the `/wp-content/plugins/` directory
2. Activate the plugin through the 'Plugins' menu in WordPress

Frequently Asked Questions
--------------------------

### How do I order Page Parts?

Either enter numbers in the order fields or drag them into the order you want.

### What changed in version 1.6?

Version 1.6 adds duplication tools for supported post types and page parts. You can now duplicate a page together with its full page part hierarchy, duplicate an individual page part with its nested children, and control duplicable post types or excluded meta keys with new filters.
